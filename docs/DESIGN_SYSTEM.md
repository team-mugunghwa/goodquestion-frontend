# 디자인 시스템

화면을 하나씩 따로 만들 예정이라, **먼저 정해 두지 않으면 12개 화면이 12가지
디자인**이 됩니다. 이 문서는 그걸 막기 위한 최소한의 합의입니다.

- 토큰 코드: `lib/core/theme/` · `lib/core/constants/app_icons.dart`
- 폰트 설치: [`assets/fonts/README.md`](../assets/fonts/README.md)
- 화면 프롬프트에 붙일 요약: [14장](#14-화면-하나-만들-때-붙일-블록)

> 여기 없는 값이 필요하면 **임의로 만들지 말고 이 문서에 추가**한 뒤 쓰세요.
> `lib/core/theme/` 는 충돌이 잦은 폴더입니다 —
> 고치기 전에 팀 채널에 알립니다. ([CONVENTIONS.md](CONVENTIONS.md#6-충돌이-자주-나는-파일))

## 1. 이 앱이 어떻게 생겨야 하는가

로고가 이미 답을 반쯤 주고 있습니다. 부풀어 오른 3D 말풍선, 파스텔 민트→그린
그라디언트, 둥근 워드마크. 여기서 세 가지가 따라 나옵니다.

**말풍선이 기본 단위입니다.** 이 서비스의 주제는 "말"입니다. 그래서 화면의
기본 그릇은 사각 카드가 아니라 **말풍선**입니다. 캐릭터 대사, 아이 발화,
미션, 힌트, 단어 뜻 — 전부 같은 계열의 둥근 형태를 쓰고 **꼬리의 방향과
면 색으로 누가 말했는지**를 구분합니다. 이게 이 앱의 서명입니다.
다른 곳에서 튀는 장식을 하지 마세요.

**낮에서 시작해 밤에서 끝납니다.** 홈·이야기·활동은 옅은 하늘색 낮 배경,
별가루를 받는 완료 화면과 내 행성은 밤 배경입니다. 배경이 바뀌는 것 자체가
"오늘 이야기를 끝냈다"는 신호입니다. 그래서 순서를 섞으면 안 됩니다.

**따뜻한 색은 별가루뿐입니다.** 화면 전체가 차가운 파스텔이라 노란빛이
나오면 눈이 자동으로 갑니다. 이 한 발을 보상에만 쓰세요.
경고에도, 강조에도, 링크에도 노랑을 쓰지 않습니다.

### 하지 않는 것

- 네온·형광, 검정 배경 + 원색 조합 — 이 앱은 자기 전에도 켜는 앱입니다
- 캐릭터가 아닌 곳에서의 과한 애니메이션 — 아이의 주의는 캐릭터에게 가야 합니다
- 아이 화면의 빨강 — STT 실패도, 순서 오답도 실패가 아닙니다 (PRD §6)
- 아이콘 하나로 뜻을 전달하기 — 초1~3은 아이콘 관습을 아직 모릅니다

## 2. 두 개의 세계

같은 앱이지만 **아이 화면과 보호자 화면은 다르게 생겨야 합니다.** 아이는 못
읽고, 보호자는 읽으러 옵니다. 화면을 만들기 전에 어느 쪽인지부터 정하세요.

| | 아이 화면 | 보호자 화면 |
|---|---|---|
| 화면 | 홈 · 이야기 · 장면 · 활동 · 행성 · 단어장 | 로그인 · 마이페이지 · 리포트 · 설정 |
| 바탕 | `AppCanvas.day` / `.night` (그라디언트) | `AppCanvas.guardian` (단색) |
| 폰트 | `AppFonts.display` (나눔스퀘어라운드) | `AppFonts.body` (Pretendard) |
| 본문 크기 | 24sp | 16sp |
| 한 화면의 선택지 | **최대 3개** | 제한 없음 |
| 터치 타겟 | 64 / 88 / 120 | 48 |
| 모서리 | 24 · 32 | 16 |
| 글자의 역할 | 보조 (음성이 본체) | 본체 |
| 색 | 밝은 면 + 그림자 | 흰 카드 + 얇은 테두리 |
| 에러 표현 | 캐릭터의 말로, 주황 | 빨강 허용 |

경계에 있는 화면이 하나 있습니다 — **마이페이지(`/mypage`)**. 하단 내비에
있어서 아이가 누를 수 있지만 내용은 보호자 것입니다. 아이 화면 크기로
그리되 **리포트 진입은 보호자 확인 게이트 뒤에** 둡니다. (PRD F-09)

## 3. 색

토큰: `lib/core/theme/app_colors.dart`

### 브랜드

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `brandMint` | `#8FD4E3` | 면·장식 |
| `brandBlue` | `#83B9DD` | 면·장식 |
| `brandGreen` | `#A0CE99` | 면·장식 |
| `brandBlueDeep` | `#2A6E9E` | **글자·아이콘·주 버튼** |
| `brandGreenDeep` | `#387C4C` | **글자·아이콘·성공** |
| `brandBlueSurface` | `brandBlue` 10% | 아이 발화 말풍선·미션 배너·칩·선택된 탭의 면 |

> 흰 카드 위에 한 겹 더 얹는 옅은 면이 필요하면 **알파를 직접 정하지 말고**
> `brandBlueSurface` 를 쓰세요. 각자 8%·12%·15% 를 고르면 같은 뜻의 면이
> 화면마다 다른 색이 됩니다.

> ⚠️ 파스텔 3형제는 흰 배경 대비가 2:1 근처입니다. **글자로 쓰면 안 읽힙니다.**
> 글자에는 반드시 `Deep` 을 쓰세요.

### 잉크 (글자·선)

`ink900 #16233F` 본문 · `ink700 #33456B` 부제 · `ink500 #5A6A8A` 캡션 ·
`ink300 #C2CCDB` 테두리 · `ink100 #E4E9F2` 구분선

순수 검정을 쓰지 않습니다. 파랑기가 도는 남색이 파스텔 위에서 덜 딱딱합니다.

### 바탕

| 토큰 | 값 | 화면 |
|---|---|---|
| `dayGradient` | `#EAF7FA` → `#F0F7EC` | 아이 화면 기본 |
| `nightGradient` | `#16233F` → `#2B3E66` | 완료 · 내 행성 · 상점 |
| `guardianCanvas` | `#F6F8FA` | 보호자 화면 |
| `surface` | `#FFFFFF` | 카드 · 말풍선 |

### 별가루 — 화면에서 유일하게 따뜻한 색

| 토큰 | 값 | 쓰는 법 |
|---|---|---|
| `stardust` | `#FFC24B` | **밤 배경 위에서만 글자로.** 대비 9.7:1 |
| `stardustDeep` | `#E39A16` | 테두리·아이콘 |
| `stardustGlow` | `#FFF3D2` | 낮 배경에서의 칩 면 (글자는 `ink900`) |

낮 배경에서 `stardust` 로 글씨를 쓰면 대비 1.6:1 로 안 보입니다. 낮에서는
**면으로**, 밤에서는 **글자로** 씁니다.

### 시맨틱

| 토큰 | 값 | 뜻 |
|---|---|---|
| `success` | `#387C4C` | 미션 통과, 저장 완료 |
| `caution` / `cautionSurface` | `#B4682A` / `#FDEBD8` | "한 번 더 해볼까?" — 아이에게 보이는 유일한 경고색 |
| `danger` | `#B3403C` | **보호자 화면 전용.** 아이 화면 금지 |
| `focus` | `#2A6E9E` | 키보드 포커스 링. 어디서나 같은 색 |

### 캐릭터의 마음(mood)은 색으로 표현하지 않습니다

PRD F-06 의 `character_state.mood` 는 **표정 에셋과 모션**이 담당합니다.
말풍선 색을 mood 에 따라 바꾸면 "따뜻한 색 = 별가루" 규칙이 무너지고,
아이는 색보다 얼굴을 훨씬 빨리 읽습니다.

## 4. 타이포그래피

토큰: `lib/core/theme/app_typography.dart` · 설치: [`assets/fonts/README.md`](../assets/fonts/README.md)

### 폰트 두 개

| 역할 | 폰트 | 라이선스 |
|---|---|---|
| 아이 화면 제목·버튼·대사 | **나눔스퀘어라운드** (`AppFonts.display`) | 네이버 나눔글꼴 라이선스 — 무료·상업적 이용·임베딩 허용 |
| 본문·보호자 화면 전체 | **Pretendard** (`AppFonts.body`) | SIL Open Font License 1.1 |

나눔스퀘어라운드를 고른 이유는 **로고 워드마크와 같은 둥근 획**이기 때문입니다.
로고 옆에 놓았을 때 다른 회사 글씨처럼 보이지 않는 무료 한글 폰트가 흔치 않습니다.
Pretendard 는 숫자·영문이 정갈해서 리포트의 수치와 날짜에 적합합니다.

**세 번째 폰트를 넣지 마세요.** 손글씨체를 아이 화면에 넣고 싶어질 텐데,
저학년은 아직 글자 모양을 배우는 중이라 변형된 자소가 읽기를 방해합니다.

### 크기 — 태블릿(≥840dp) 기준

**아이 화면** (`AppTypography.kid*`)

| 토큰 | 크기/행간 | 굵기 | 쓰는 곳 |
|---|---|---|---|
| `kidHero` | 44 / 1.25 | 800 | 완주 축하, 획득 별가루. **화면당 한 번** |
| `kidTitle` | 32 / 1.3 | 800 | 화면 제목, 미션 제목, 이야기 제목 |
| `kidBody` | 24 / 1.55 | 400 | 대사, 상황 설명, 미션 지시문 |
| `kidTranscript` | 24 / 1.5 | 500 | STT 실시간 변환 (Pretendard, 확정 전) |
| `kidButton` | 22 / 1.2 | 800 | 버튼 안의 한 단어 |
| `kidLabel` | 18 / 1.3 | 700 | 별가루 개수, 아이템 가격 |

**보호자 화면** — `Theme.of(context).textTheme` 을 그대로 씁니다.
`headlineLarge` 28 / `titleLarge` 20 / `titleMedium` 17 / `bodyMedium` 16 /
`bodySmall` 13. 리포트에서 아이 발화를 인용할 때만 `AppTypography.quote`
(나눔스퀘어라운드 18) 로 우리 문장과 구분합니다.

폰에서는 `AppTypography.scaled(style, context.windowSize)` 로 줄입니다.
(expanded 100% · medium 92% · compact 84%)

### 문장 규칙

- **아이 화면 한 줄은 20자 이내.** 넘으면 폭을 늘리지 말고 문장을 자릅니다
- 말풍선 폭은 `AppSizes.bubbleMaxWidth`(560) 를 넘기지 않습니다
- 보호자 본문은 `ContentContainer`(720) 안에 둡니다
- 아이 화면에 **문단(3줄 이상)을 만들지 않습니다.** 길면 음성으로 보내세요

## 5. 간격 · 모서리 · 터치 타겟

토큰: `lib/core/theme/app_spacing.dart`

**간격** `xs 4 · sm 8 · md 16 · lg 24 · xl 32 · xxl 48 · xxxl 64`
아이 화면은 `lg` 부터 시작합니다. 요소가 크니 여백도 커야 덜 답답합니다.

**모서리** `xs 8 · sm 12 · md 16 · lg 24 · xl 32 · pill 999`
아이 화면은 `lg`~`xl`, 보호자 화면은 `md`. **한 화면에서 3종류 이상 섞지 마세요.**

**터치 타겟** — 초1~3의 손가락은 어른보다 크게 흔들립니다. 48dp 로는 부족합니다.

| 토큰 | 크기 | 쓰는 곳 |
|---|---|---|
| `mic` | 120 | 마이크. 화면에서 가장 큰 조작 요소, **항상 같은 자리** |
| `tapChildPrimary` | 88 | 다음, 보내기, 이야기 시작하기 |
| `tapChildSecondary` | 64 | 다시 듣기, 단어 담기, 뒤로 |
| `tapGuardian` | 48 | 보호자 화면 전부 |
| `planetControl` | 72 | 행성 조작 3버튼 (회전·확대·되돌리기) |

아이 화면의 **누를 수 있는 것 사이 간격은 최소 24dp**. 오터치가 곧 좌절입니다.

**그 밖의 고정 크기** — `illustration 160` (빈·에러 화면의 캐릭터),
`bubbleMaxWidth 560`, `bottomNav 80`(최소 높이. 글자 확대 설정에서는 늘어납니다).

## 6. 표면과 그림자

토큰: `lib/core/theme/app_shadows.dart`

단계는 **두 개뿐**입니다. Material 의 elevation 0~24 를 쓰지 마세요.

- `soft` — 바닥에 놓인 것: 카드, 목록 항목, 하단 내비
- `lift` — 떠 있는 것: 말풍선, 시트, 상점 카드, 큰 버튼
- `stardustGlow` — 별가루가 붙은 것. 그림자가 아니라 **빛**이라 사방으로 퍼집니다

검정 그림자를 쓰지 않습니다. 잉크색을 8%·12% 로 깐 그림자가 파스텔 위에서
회색 때처럼 보이지 않습니다.

**밤 배경 위에서는 그림자가 안 보입니다.** 흰 카드를 얹으면 너무 튀고요.
`nightSurface`(흰색 12%) 면 + `nightBorder`(흰색 20%) 테두리로 분리합니다.

## 7. 아이콘

토큰: `lib/core/constants/app_icons.dart`

**Flutter 내장 Material 아이콘의 `_rounded` 변형만 씁니다.** 아이콘 패키지를
추가하지 않습니다 — 내장 세트로 충분하고, 섞으면 굵기와 광학 크기가 어긋납니다.
`Icons.home`(각진 기본형)을 쓰면 그 화면만 튑니다.

크기는 아이 화면 40, 보호자 화면 24 (`AppSizes.iconChild` / `iconGuardian`).

예외가 하나 있습니다 — **칩·라벨 옆에 붙는 인라인 글리프는 24**
(`AppSizes.iconInline`). 별가루 칩의 ✦, "더 보기 ›" 의 꺾쇠처럼 **글자에
딸린** 아이콘입니다. 18sp 라벨 옆에 40짜리 아이콘을 붙이면 글자가 아이콘의
부속처럼 보입니다. **아이가 누르는 버튼 안의 아이콘은 40이 맞습니다.**

화면에서 `Icons.mic_rounded` 를 직접 쓰지 말고 `AppIcons.speak` 을 쓰세요.
"말하기"의 아이콘을 바꿀 때 한 줄만 고치면 됩니다.

> **아이 화면에서 아이콘 단독 금지.** 아이가 누르는 버튼은
> **아이콘 + 한 단어 + 음성 안내** 세 가지를 함께 줍니다.
> 보호자 화면에서는 아이콘만 써도 됩니다.

## 8. 모션

토큰: `lib/core/theme/app_motion.dart`

이 앱에서 애니메이션은 장식이 아니라 **차례를 알려주는 신호**입니다.
아이는 글을 안 읽으므로 "지금 내 차례"를 화면 변화와 소리로 압니다. (PRD F-05)

| 토큰 | 시간 | 쓰는 곳 |
|---|---|---|
| `tap` | 120ms | 눌린 느낌 |
| `quick` | 200ms | 색·아이콘 교체 |
| `normal` | 320ms | 화면 전환, 말풍선 등장 |
| `turn` | 600ms | **차례 전환.** 일부러 느립니다 |
| `celebrate` | 1200ms | 별가루 낙하, 완주 축하. 세션에 한 번 |
| `thinkingLoop` | 1400ms | 캐릭터 대기 모션 한 주기 |
| `idleHint` | 30s | 무응답 → 힌트 (PRD 예외 경로) |

곡선은 `standard`(easeOutCubic) 기본, 아이 화면 등장은 `playful`(easeOutBack)
— 끝에서 살짝 튀어 장난감처럼 보입니다. **`Curves.linear` 금지.**

**접근성**: `respect(context, AppDurations.normal)` 로 감싸면 기기의 "동작
줄이기" 설정에서 0 이 됩니다. 전정기관이 예민한 아이가 있습니다.

### 정해진 연출 세 가지

1. **차례 전환** — 캐릭터 말풍선이 흐려지며 뒤로 물러나고(`turn`), 마이크가
   `playful` 로 커지며 링이 한 번 퍼집니다. 소리 동반
2. **말하는 중** — 마이크 주변 링이 음성 레벨에 따라 숨쉬듯 커집니다.
   파형 시각화가 아니라 **크기 하나**로만. 아이가 자기 목소리를 눈으로 봅니다
3. **별가루 낙하** — 완료 화면에서 획득 개수 안내 → 행성 진입 시 위에서
   떨어져(`fall`) 잔액 숫자에 합쳐집니다 (`celebrate`)

## 9. 소리

말이 본체인 앱이라 소리도 디자인 토큰입니다. 이름을 먼저 정해 둡니다.

`turnToChild` (내 차례) · `turnToCharacter` · `missionClear` ·
`stardustGain` · `tapSoft` · `retrySoft` (재시도 — 실패음처럼 들리면 안 됨)

- 출처는 **Kenney Audio (CC0)** 로 통일합니다. 내 행성 3D 에셋과 같은 출처라
  톤이 어긋나지 않습니다 (PRD F-08)
- 모든 효과음은 짧고(<400ms) 작습니다. 캐릭터 목소리를 덮으면 안 됩니다
- 무음 모드에서도 화면 변화만으로 차례를 알 수 있어야 합니다

## 10. 컴포넌트 규칙

새 컴포넌트를 만들기 전에 여기 있는지 먼저 보세요.

### 이미 만들어져 있는 것 (`lib/core/widgets/`)

| 위젯 | 하는 일 |
|---|---|
| `AppCanvas.day/.night/.guardian` | 화면 바탕 세 종류 |
| `PressScale` | 누르면 살짝 줄어드는 터치 영역. 카드·탭·버튼의 바닥 |
| `KidSpeechBubble` | 말풍선 (`KidSpeaker.character` 왼쪽·흰 면 / `.child` 오른쪽·`brandBlue` 10% 면). 꼬리를 **박스 안쪽에** 그려서 `height` 하나로 세로 예산을 짤 수 있습니다 |
| `KidPrimaryButton` | 아이 화면 주 버튼 (88 · pill · 아이콘+한 단어) |
| `StardustChip.day/.night` | 별가루 잔액 칩 |
| `AppBottomNav` | 하단 내비 4탭. 홈·이야기·단어장·마이페이지가 공유 |
| `AppKidErrorView` | 아이 화면의 에러 — 캐릭터 + 큰 버튼 하나 |
| `AppLoadingView` / `AppErrorView` / `AppEmptyView` | 보호자 화면용 |

`PressScale` 을 쓰면 포커스 링·키보드 조작·시맨틱스가 같이 따라옵니다.
`GestureDetector` 로 직접 감싸면 그게 전부 빠집니다.

**말풍선** — 반경 `xl`, 그림자 `lift`, 최대 폭 560.
캐릭터는 왼쪽 + 흰 면, 아이는 오른쪽 + `brandBlue` 10% 면. 꼬리는 화자 쪽으로.
확정 전 STT 텍스트는 테두리를 점선으로 두어 "아직 안 보냄"을 보여줍니다.

**마이크 버튼** — 지름 120, `pill`, `brandBlueDeep` 면 + 흰 아이콘.
**화면 하단 중앙에 고정.** 장면이 바뀌어도 자리가 바뀌지 않습니다.

**미션 배너** — 장면 상단. `stardustGlow` 가 아니라 `brandBlue` 10% 면 +
`AppIcons.mission`. 미션은 보상이 아니라 할 일입니다.

**별가루 칩** — `pill`, 낮에서는 `stardustGlow` 면 + `ink900` 글자,
밤에서는 투명 면 + `stardust` 글자. 홈 위젯·상점·완료 화면에서 같은 모양.

**이야기 카드** — 반경 `xl`, 표지는 **세로 2:3**(`StoryThumbnail.portrait`),
제목(`kidTitle`) + 예상 시간·주제 칩. 난이도는 숫자가 아니라 점 3개로.

> **표지는 자르지 않습니다.** 원본이 전부 세로(1024×1536)라 16:9로 담으면 세로 44%만
> 남고 인물의 얼굴이 잘립니다. 자를 수밖에 없는 자리라면 그 비율로 그린 그림을 따로
> 씁니다 — 홈 히어로가 그렇게 **가로 전용 표지(2.5:1)** 를 갖게 됐습니다.
> → [`COVER_ART_GUIDE.md` 7장](COVER_ART_GUIDE.md#7-표지는-자르지-않는다)
>
> 세로 표지는 폭이 곧 높이(×1.5)라 **세로가 비쌉니다.** 홈처럼 첫 화면 예산이 빠듯한
> 곳에서는 카드(제목 32sp + 칩)를 세울 자리가 안 나옵니다 — 그때는 표지만 세우고
> 제목을 18sp 라벨로 밑에 다는 "책장"을 씁니다. (`RecommendedStoriesSection`)

**히어로 카드** — 홈 섹션2(`HomeHeroCard`) 하나뿐입니다. 카드가 **표지 패널 + 흰 글자
면**으로 나뉩니다. 왼쪽 패널은 **가로 전용 표지 2.5:1**, 오른쪽 흰 면에 제목 · 진행 점 ·
CTA 를 세로 가운데로 세웁니다. "이어보던 이야기" 같은 표식은 이미지 위에 얹는 **흰 알약**
입니다.

> **자르지 않습니다.** 패널 비율 = 그림 비율이라 `BoxFit.cover` 가 잘라낼 게 없습니다.
> 가로 표지가 아직 없는 편은 **세로 2:3 표지를 왼쪽에 세우고**, 그쪽도 자르지 않습니다.
> → [`COVER_ART_GUIDE.md` 8장](COVER_ART_GUIDE.md#8-가로-전용-표지-홈-히어로--확정-규격)
>
> **스크림은 없습니다.** 예전에는 표지를 카드 전폭 배경으로 깔고 흰 글자를 얹느라 검은
> 스크림(합성 0.61~0.69)을 계산해야 했습니다. 사진과 글자가 자리를 나눠 가지면서 그
> 계산 자체가 없어졌고, 글자·진행 점은 잉크색(`ink900`/`ink700`)과 `brandBlueDeep` 으로
> 돌아왔습니다. **사진 위에 글자를 얹는 자리는 이제 앱에 없습니다.**
>
> 카드 높이는 글자 기둥이 정하고(제목 + 진행 + 88 버튼 + 여백 ≈ 243), 패널 폭은 거기에
> 비율을 곱해 나옵니다. 글자 칸이 512dp 밑으로 내려가는 폭(1024 이하)에서는 **글자를
> 줄이지 않고** 세로 2:3 패널로 바꿉니다. 폰은 2.5:1 패널을 옆에 세울 수 없어(폭 625dp
> 필요) 띠를 위에 얹고 글자를 아래에 쌓습니다.

**상점 아이템** — 3D 미리보기 + 가격 칩. 살 수 없으면 흐리게 + 부족한 개수 표시,
아직 안 열렸으면 `lockedScrim` 실루엣 + 해금 조건을 그림으로. (PRD F-08)

**리포트 블록** — 역량명 → 이번 활동의 특징 → 근거 발화(`quote`) → 잘한 점 →
보완할 부분 순서 고정. **잘한 점이 항상 먼저**입니다. 내부 태그(DECISION,
REASON 등)를 절대 노출하지 않습니다. (PRD F-09)

**빈 화면** — `AppStateViews` 를 씁니다. 아이 화면의 빈 상태는 캐릭터가
말을 거는 형태로, 보호자 화면은 다음 할 일을 알려주는 문장으로.

## 11. 문구

디자인만큼 문구가 화면의 인상을 정합니다.

### 아이에게

- **한 화면에 한 가지만 시킵니다.** "먼저 ~하고 그다음 ~해요" 금지
- 버튼은 **한 단어**: `말하기` `다음` `다시 듣기` `담기`
- 실패를 실패라고 부르지 않습니다.
  ❌ "인식하지 못했어요" → ✅ "잘 안 들렸어. 한 번만 더 말해 줄래?"
- 캐릭터가 말합니다. 시스템이 말하지 않습니다. 안내문에도 캐릭터 톤 유지
- 존댓말/반말은 **캐릭터별로 정하고 끝까지 지킵니다**

### 보호자에게

- 사실 → 근거 → 제안 순서. 단정적 부정 표현 금지 (PRD F-09)
  ❌ "논리력이 부족합니다" → ✅ "이유를 말한 문장이 1회 있었습니다"
- 아이를 다른 아이와 비교하는 문장을 만들지 않습니다. 랭킹은 범위 밖입니다 (PRD §3)
- 버튼 이름과 결과가 같은 말이어야 합니다. `저장` 을 눌렀으면 `저장했습니다`

## 12. 접근성 — 화면마다 확인

- [ ] 본문 대비 4.5:1 이상 (파스텔 3형제를 글자로 쓰지 않았는가)
- [ ] 색만으로 뜻을 전달하지 않는가 (미션 통과 = 초록 + 체크 아이콘 + 소리)
- [ ] 누를 수 있는 것이 최소 크기를 넘는가 (아이 64 / 보호자 48)
- [ ] `respect()` 로 "동작 줄이기" 설정을 존중하는가
- [ ] 아이콘 버튼에 `Semantics` 또는 `tooltip` 이 있는가
- [ ] 태블릿 **세로·가로 모두** 확인했는가 (PRD §6)
- [ ] `MediaQuery.textScalerOf` 를 1.3배로 키워도 레이아웃이 안 깨지는가

[디자인 규칙 — docs/DESIGN_SYSTEM.md]
- 이 화면은 (아이 / 보호자) 화면이고 바탕은 AppCanvas.(day/night/guardian) 이다.
