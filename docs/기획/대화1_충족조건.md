맞아요. 먼저 대화 충족 요건을 확정한 뒤, 그 판정 결과에 표정과 동작을 연결해야 합니다. 기준은 CSV의 헤더 다음 첫 번째 데이터 행입니다.

## 1. 이 장면의 충족 요건

아이의 누적 발화에서 아래 3가지가 모두 확인되면 대화를 즉시 종료합니다.

| 요소            | 충족 기준                       | 충족 예시                       | 미충족 예시            |
| ------------- | --------------------------- | --------------------------- | ----------------- |
| `EMOTION`     | 며느리의 감정이나 아이 자신의 감정을 직접 표현  | “계속 참으면 많이 힘들 것 같아요.”       | “괜찮아요.”           |
| `PERSPECTIVE` | 며느리 또는 가족의 입장과 반응을 헤아림      | “가족들도 처음에는 놀라지만 이해해 줄 거예요.” | “방귀는 원래 나오는 거예요.” |
| `SOLUTION`    | 현재의 어려움을 줄일 수 있는 구체적인 행동 제안 | “가족들에게 먼저 솔직하게 말해 보세요.”     | “어떻게든 해봐요.”       |

한 문장으로 여러 요소를 동시에 충족할 수 있습니다.

> “계속 참으면 힘들 것 같아요. 가족들도 이해해 줄 테니 솔직하게 말해 보세요.”

이 답변은 `EMOTION + PERSPECTIVE + SOLUTION`을 모두 충족하므로 1턴 후에도 종료할 수 있습니다.

### 판정할 때 주의할 점

* “계속 참아요”는 행동이지만 현재 문제를 반복·악화시키므로 `SOLUTION`으로 인정하지 않습니다.
* “그냥 방귀 뀌어요”는 몸의 불편을 해소하는 구체적인 행동이므로 `SOLUTION`은 인정할 수 있습니다. 다만 가족의 입장을 고려하지 않았다면 `PERSPECTIVE`는 미충족입니다.
* 놀리거나 비난하는 말은 감정 단어가 들어가더라도 `EMOTION`으로 인정하지 않습니다.
* 같은 발화에서 여러 요소가 명확하면 모두 인정합니다.
* 앞에서 충족된 요소는 다음 턴에도 계속 유지합니다.
* STT 실패, 무응답, 재녹음은 대화 턴으로 세지 않습니다.
* 아이가 확정해서 보낸 발화는 요소가 없어도 1턴으로 계산합니다.

## 2. 종료 규칙

`preferred_turns=2`는 **최소 턴 게이트**입니다. 요소를 다 채워도 2턴 전에는 닫히지 않습니다.

```text
아이 발화 분석
→ 이번 발화에서 충족된 요소 추출
→ 이전 충족 요소와 합산
→ 3개 요소 모두 충족 그리고 2턴 이상: 종료
→ 미충족이고 현재 1~3턴: 부족한 요소만 재질문
→ 미충족이고 4턴 도달: 강제 통과
→ 짧은 공감 반응
→ 고정 마지막 대사
```

따라서 실제 대화는 2~4턴 사이에서 끝납니다.

* 1턴 만에 3개 충족: 그래도 2턴째까지 이어간 뒤 종료
* 보통 2턴 안에 충족: 정상 종료
* 2턴 후에도 부족함: 3~4턴 추가 질문
* 4턴까지 부족함: 평가하거나 지적하지 않고 종료

이 장면은 `mission_config`가 비어 있으므로 별도 미션 화면은 나오지 않습니다.

## 3. 부족한 요소별 재질문

| 남은 요소                    | 캐릭터의 재질문 방향                           |
| ------------------------ | ------------------------------------- |
| `EMOTION`                | “계속 참는 내 마음은 어떨 것 같아?”                |
| `PERSPECTIVE`            | “내 방귀를 알게 되면 가족들은 어떻게 생각할까?”          |
| `SOLUTION`               | “그럼 내가 어떻게 해 보면 좋을까?”                 |
| `EMOTION + PERSPECTIVE`  | “내 마음은 어떨 것 같고, 가족들은 어떻게 생각할까?”       |
| `EMOTION + SOLUTION`     | “계속 참는 내 마음은 어떨 것 같아? 내가 어떻게 하면 좋을까?” |
| `PERSPECTIVE + SOLUTION` | “가족들은 어떻게 생각할까? 내가 어떻게 말하면 좋을까?”      |

질문 문구는 매번 똑같이 반복하지 않고, 의미는 유지하면서 캐릭터 말투에 맞게 바꿀 수 있습니다.

## 4. 표정과 동작 상태 확정안

이 장면에는 다음 8가지 상태가 필요합니다.

| 상태 코드              | 사용 시점               | 표정과 동작                                            |
| ------------------ | ------------------- | ------------------------------------------------- |
| `OPENING_WORRIED`  | 첫 대사                | 허리를 숙이고 두 손을 아랫배에 모음. 걱정스러운 눈썹, 아래로 향한 시선, 긴장된 입  |
| `LISTENING`        | 아이가 말하는 동안          | 고개를 조금 들고 아이를 바라봄. 천천히 눈을 깜빡이고 몸 움직임을 멈춤          |
| `THINKING`         | 답변 분석 중             | 시선을 잠시 옆으로 옮기고 고개를 작게 끄덕임. 가벼운 호흡 동작              |
| `COMFORTED`        | `EMOTION` 새로 충족     | 눈썹의 긴장이 풀리고 작게 미소. 어깨가 조금 내려감                     |
| `CONSIDERING`      | `PERSPECTIVE` 새로 충족 | 고개를 살짝 기울이고 생각하는 눈빛. 한 손을 가슴이나 턱 가까이 이동           |
| `HOPEFUL`          | `SOLUTION` 새로 충족    | 상체를 조금 펴고 눈이 밝아짐. 한 손을 살짝 펼치며 희망적인 반응             |
| `HURT_OR_CONFUSED` | 놀림·비난·무관한 답변        | 시선을 내리거나 고개를 갸웃함. 울거나 과도하게 상처받지 않고 조심스럽게 재질문      |
| `CLOSING_HESITANT` | 목표 충족 또는 4턴 도달      | 다시 한 손을 배에 대고 다른 손으로 옷자락을 잡음. 희망은 생겼지만 아직 망설이는 표정 |

여러 요소가 한꺼번에 충족되면 다음 우선순위로 표정을 선택하면 됩니다.

```text
부정적·놀림 반응
→ HURT_OR_CONFUSED 우선

일반적인 답변
→ SOLUTION: HOPEFUL
→ PERSPECTIVE: CONSIDERING
→ EMOTION: COMFORTED
```

모두 충족됐을 때는 잠시 `HOPEFUL` 표정을 보여준 후 `CLOSING_HESITANT`로 전환합니다.

마지막에는 반드시 다음 대사를 재생합니다.

> “그래도 아직은 못 말하겠어. 조금만 더 참아 볼게.”

좋은 답을 들었더라도 바로 용감해지는 장면이 아니기 때문에, 마지막 표정은 완전히 밝은 미소가 아니라 ‘조금 안심했지만 아직 두려운 상태’가 적절합니다.

구현 필드명은 공통 규칙의 `target_elements`와 CSV의 `required_elements`가 서로 다르므로, 실제 코드에서는 `required_elements` 하나로 통일하는 것이 좋습니다.
