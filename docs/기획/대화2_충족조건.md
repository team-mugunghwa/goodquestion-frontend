먼저 대화 충족 요건을 확정한 뒤, 그 판정 결과에 시아버지의 표정과 동작 상태를 연결합니다. 기준은 CSV의 `#=3`, `scene_order=5`인 시아버지 대화 장면입니다.

## 1. 이 장면의 충족 요건

아이의 누적 발화에서 아래 4가지가 모두 확인되면 대화를 즉시 종료합니다.

| 요소 | 충족 기준 | 충족 예시 | 미충족 예시 |
| --- | --- | --- | --- |
| `PERSPECTIVE` | 시아버지 또는 며느리의 상황과 입장을 고려해 말함 | “며느리도 일부러 그런 게 아니에요.” | “방귀가 정말 크네요.” |
| `EMPATHY` | 며느리의 부끄럽고 속상한 마음을 이해하고 배려함 | “며느리가 얼마나 창피하고 속상하겠어요.” | “며느리가 잘못했어요.” |
| `REASON` | 며느리가 방귀를 오래 참았던 까닭이나 크게 터진 까닭을 설명함 | “오래 참아서 한꺼번에 크게 나온 거예요.” | “그냥 실수한 거예요.” |
| `REQUEST` | 시아버지에게 며느리를 이해하기 위한 구체적인 행동을 요청함 | “친정으로 보내기 전에 며느리 이야기를 한 번만 들어 주세요.” | “잘해주세요.” |

한 문장으로 여러 요소를 동시에 충족할 수 있습니다.

> “시아버지도 갑자기 놀라셨겠지만, 며느리는 일부러 그런 게 아니고 오래 참아서 크게 나온 거예요. 많이 속상할 테니 친정으로 보내기 전에 이야기를 한번 들어 주세요.”

이 답변은 `PERSPECTIVE + EMPATHY + REASON + REQUEST`를 모두 충족하므로 1턴 후에도 종료할 수 있습니다.

### 판정할 때 주의할 점

* “며느리를 더 혼내 주세요” 또는 “친정으로 보내세요”는 구체적인 요청이더라도 현재 갈등을 악화시키므로 `REQUEST`로 인정하지 않습니다.
* “화내지 마세요”는 요청의 방향은 있으나 시아버지가 무엇을 해야 하는지 구체적이지 않으므로 `REQUEST` 충족으로 보기 어렵습니다.
* “시아버지도 놀라셨을 것 같아요”는 시아버지의 입장을 고려하므로 `PERSPECTIVE`는 인정할 수 있습니다. 다만 며느리의 감정을 이해한 말이 없다면 `EMPATHY`는 미충족입니다.
* “며느리가 속상하겠어요”는 `EMPATHY`는 인정할 수 있지만, 방귀가 크게 나온 까닭을 설명하지 않았다면 `REASON`은 미충족입니다.
* “일부러 그런 게 아니에요”는 며느리의 입장을 고려하므로 `PERSPECTIVE`로 인정합니다. 다만 구체적인 까닭이 없다면 `REASON`은 미충족입니다.
* 놀리거나 비난하는 말은 관련 단어가 들어가더라도 목표 요소로 인정하지 않습니다.
* 같은 발화에서 여러 요소가 명확하면 모두 인정합니다.
* 앞에서 충족된 요소는 다음 턴에도 계속 유지합니다.
* STT 실패, 무응답, 재녹음은 대화 턴으로 세지 않습니다.
* 아이가 확정해서 보낸 발화는 요소가 없어도 1턴으로 계산합니다.

## 2. 종료 규칙

`preferred_turns=3`은 최소 턴이 아니라 권장 대화 길이로 봅니다.

```text
아이 발화 분석
→ 이번 발화에서 충족된 요소 추출
→ 이전 충족 요소와 합산
→ 4개 요소 모두 충족: 즉시 종료
→ 미충족이고 현재 1~4턴: 부족한 요소만 재질문
→ 미충족이고 5턴 도달: 강제 통과
→ 현재까지의 발화에 짧게 반응
→ 고정 마지막 대사
```

따라서 실제 대화는 1~5턴 사이에서 끝납니다.

* 1턴 만에 4개 충족: 1턴 종료
* 보통 3턴 안에 충족: 정상 종료
* 3턴 후에도 부족함: 4~5턴 추가 질문
* 5턴까지 부족함: 평가하거나 지적하지 않고 종료

이 장면은 `mission_config`가 비어 있으므로 별도 미션 화면은 나오지 않습니다.

마지막에는 반드시 CSV의 고정 대사를 그대로 재생합니다.

> “흥, 그래도 도저히 이런 며느리와는 함께 살 수 없으니 친정으로 데려다줘야겠다.”

좋은 답을 들었더라도 이 장면 안에서 시아버지의 생각이 완전히 바뀌지는 않습니다. 마지막 상태에는 아이의 말을 일부 고려한 흔적은 남기되, `remaining_worries`와 다음 이야기 흐름을 유지합니다.

## 3. 부족한 요소별 재질문

이미 충족된 요소는 다시 묻지 않고, 남아 있는 요소만 질문에 반영합니다.

| 남은 요소 | 캐릭터의 재질문 방향 |
| --- | --- |
| `PERSPECTIVE` | 며느리가 일부러 그런 것인지, 시아버지와 며느리는 각각 어떤 입장일지 생각하게 함 |
| `EMPATHY` | 모두가 놀란 상황에서 며느리는 어떤 마음일지 생각하게 함 |
| `REASON` | 며느리가 왜 그렇게 요란한 방귀를 뀌게 되었는지 까닭을 설명하게 함 |
| `REQUEST` | 시아버지가 지금 며느리에게 무엇을 해 주면 좋을지 구체적으로 말하게 함 |
| `PERSPECTIVE + EMPATHY` | 며느리가 일부러 그런 것인지와 지금 어떤 마음일지를 함께 생각하게 함 |
| `PERSPECTIVE + REASON` | 며느리의 입장과 방귀가 크게 나온 까닭을 함께 설명하게 함 |
| `PERSPECTIVE + REQUEST` | 며느리의 입장을 생각한 뒤 시아버지가 할 행동을 구체적으로 부탁하게 함 |
| `EMPATHY + REASON` | 며느리의 마음과 그렇게 된 까닭을 함께 이야기하게 함 |
| `EMPATHY + REQUEST` | 며느리의 마음을 고려해 시아버지가 어떻게 해 주면 좋을지 말하게 함 |
| `REASON + REQUEST` | 방귀가 크게 나온 까닭을 설명한 뒤 시아버지에게 구체적인 행동을 부탁하게 함 |

세 가지 이상이 남았을 때도 질문 하나에 모든 요소를 억지로 넣지 않습니다. 우선 현재 답변과 가장 자연스럽게 이어지는 한두 요소를 질문하고, 다음 턴에서 나머지 요소를 확인합니다.

질문 문구는 매번 똑같이 반복하지 않고 의미는 유지하면서, 호들갑스럽고 고집이 있지만 아이를 위압하지 않는 시아버지 말투로 바꿀 수 있습니다.

## 4. 표정과 동작 상태 확정안

이 장면은 별도 이미지 6개와 Flutter 런타임 상태 3개로 구성합니다.

모든 상태에서 얼굴과 몸은 정면을 향하고 양쪽 눈은 화면 앞의 아이를 바라봅니다. 고개를 조금 기울일 수는 있지만, 옆이나 아래로 시선을 돌리지 않습니다.

### 별도 이미지 에셋 상태

| 상태 코드 | 발생 조건 | 표정과 동작 | 파일명 |
| --- | --- | --- | --- |
| `OPENING_UPSET` | 장면 시작과 고정 첫 대사 | 놀라 크게 뜬 눈, 안쪽이 내려간 굵은 눈썹, 벌어진 입. 상체를 약간 앞으로 세우고 양팔을 바깥으로 펼치지만 아이를 손가락으로 위협하지 않음 | `character_opening.png` |
| `CONSIDERING` | `PERSPECTIVE` 또는 `REASON`이 새롭게 충족됨 | 눈썹의 긴장이 조금 풀리고 입을 다문 채 생각하는 표정. 고개를 아주 조금 기울이고 한 손을 가슴 가까이 둠 | `character_considering.png` |
| `SOFTENED` | `EMPATHY`가 새롭게 충족됨 | 눈매와 눈썹이 부드러워지고 입꼬리의 긴장이 약해짐. 어깨가 조금 내려가며 양손의 힘이 풀림 | `character_softened.png` |
| `RELUCTANT` | `REQUEST`가 새롭게 충족됨 | 부탁을 이해했지만 아직 동의하지 않은 표정. 한쪽 눈썹을 조금 올리고 입술을 가볍게 다문 채 한 손바닥을 작게 펼침 | `character_reluctant.png` |
| `HURT_OR_CONFUSED` | 놀림, 비난, 무관하거나 매우 모호한 답변 | 눈썹을 살짝 모으고 입을 작게 다문 당황한 표정. 고개를 조금 기울이고 두 손을 몸 앞쪽에 모음. 화를 키우거나 아이를 혼내지 않음 | `character_hurt_confused.png` |
| `CLOSING_STUBBORN` | 모든 요소 충족 또는 5턴 도달 후 고정 마지막 대사 | 처음보다 화는 줄었지만 고집은 남은 표정. 눈썹을 약간 찌푸리고 입을 한쪽으로 다문 채 팔을 느슨하게 몸 앞에 둠 | `character_closing.png` |

`PERSPECTIVE`와 `REASON`은 모두 시아버지가 며느리의 상황을 새롭게 생각해 보는 인지적 변화이므로 `CONSIDERING` 이미지 하나로 합칩니다. 불필요하게 유사한 에셋을 늘리지 않습니다.

`EMPATHY`는 며느리의 마음을 의식하며 감정적으로 누그러지는 변화이므로 `SOFTENED`로 구분합니다.

`REQUEST`는 아이의 부탁을 알아들었지만 아직 결정을 바꾸지는 않은 상태이므로 밝은 희망이나 동의가 아니라 `RELUCTANT`로 표현합니다.

### Flutter 런타임 상태

| 상태 코드 | 사용 시점 | 기준 이미지 | 추천 모션 | 다음 상태 전환 |
| --- | --- | --- | --- | --- |
| `LISTENING` | 아이가 말하는 동안 | 현재 감정 상태 이미지 | 아주 미세한 호흡, 느린 눈 깜빡임, 작은 정면 끄덕임 | 아이의 확정 발화가 끝나면 `THINKING` |
| `THINKING` | 아이의 답변을 분석하는 동안 | 현재 감정 상태 이미지 | 정면 눈맞춤을 유지한 작은 고개 기울기, 짧은 눈 깜빡임 | 판정 결과에 따라 요소 반응 또는 `HURT_OR_CONFUSED` |
| `SPEAKING` | 캐릭터 대사 재생 중 | 현재 선택된 상태 이미지 | 입 주변의 미세한 말하기 변화, 손과 상체의 작은 제스처 | 대사 종료 후 `LISTENING` 또는 장면 종료 |

런타임 모션은 PNG 전체를 단순히 위아래로 이동하는 방식이 아니라, Flutter에서 눈 깜빡임·고개 각도·상체 기울기·손 제스처를 작은 범위로 조합하는 방식으로 설계합니다. 이 작업은 Rive·Spine 관절 애니메이션이 아니라 상태 이미지와 코드 모션을 결합하는 방식입니다.

## 5. 여러 요소가 동시에 충족됐을 때의 상태 우선순위

```text
놀림·비난·무관한 답변
→ HURT_OR_CONFUSED 우선

일반적인 유효 답변
→ EMPATHY 새 충족: SOFTENED
→ REQUEST 새 충족: RELUCTANT
→ PERSPECTIVE 또는 REASON 새 충족: CONSIDERING
```

한 발화에서 네 요소가 모두 충족되면 `SOFTENED`를 잠시 보여준 뒤 `CLOSING_STUBBORN`으로 전환합니다.

`REQUEST`까지 충족됐더라도 바로 밝게 웃거나 며느리를 용서한 것처럼 표현하지 않습니다. CSV의 마지막 대사와 `remaining_worries`에 맞게 고집과 망설임을 남깁니다.

## 6. 다음 단계에서 제작할 에셋

```text
scene_background_blurred.png
character_opening.png
character_considering.png
character_softened.png
character_reluctant.png
character_hurt_confused.png
character_closing.png
```

배경 1개와 투명 캐릭터 상태 이미지 6개를 제작합니다. `LISTENING`, `THINKING`, `SPEAKING`은 별도 PNG를 만들지 않고 현재 감정 이미지를 기준으로 Flutter에서 처리합니다.

구현 필드명은 공통 규칙의 `target_elements`와 CSV의 `required_elements`가 같은 의미이므로 실제 코드와 매핑 JSON에서는 `requiredElements`로 통일합니다.
